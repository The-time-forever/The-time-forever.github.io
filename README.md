# The Time Forever 🕒

一个记录学习和生活的个人博客，写点技术笔记、工具指南，也写点日常。

👉 **访问博客：[the-time-forever.github.io](https://the-time-forever.github.io/)**

## 都写些什么

内容比较杂，想到什么记什么：

- 折腾电脑时踩过的坑（Git、CLI、WSL2、Python 虚拟环境……）
- 好用的工具和软件推荐（压缩软件、妙控板手势……）
- 一些学习笔记（复变函数、离散数学……）
- 别的随手记的东西

## 关于这个仓库

博客基于 Astro + GitHub Pages 搭建，纯 Markdown 写作。

首页《绝区零》月历壁纸由 GitHub Actions 每月自动检查更新，操作说明见 [月历自动化文档](docs/calendar-automation.md)，来源验证见 [2026 年历史核查](docs/calendar-history-2026.md)。

如果你也想搭一个类似的博客，或者对某篇文章的内容有疑问、建议，欢迎提 Issue～
